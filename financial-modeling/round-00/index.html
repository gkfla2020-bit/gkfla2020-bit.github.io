No-Mouse Excel — 키보드 완전정복

마우스에 손을 떼지 않고 모델을 짓는 근본 근육
Reference: 현직 IB/리서치 모델링 컨벤션 · Wall Street Prep · Microsoft Excel 공식 단축키
Overall Progress: 0/12 Rounds
이 라운드를 먼저 읽어야 하는 이유

재무모델링에서 마우스는 '느림'의 다른 이름이다. 셀을 클릭하고, 메뉴를 뒤지고, 참조를 드래그하는 동안 사고의 흐름은 끊긴다. 현직 애널리스트가 한 시간에 짜는 모델을 초심자가 하루 종일 붙잡는 이유의 절반은 회계 지식이 아니라 손의 속도다. 이 라운드에서는:

  • 마우스 없이 시트를 이동·선택하는 법 — Ctrl+방향키, Ctrl+Shift+방향키, 이름상자로 순간이동
  • 편집의 심장 F2와 참조를 고정하는 F4 — 모델링 단축키의 8할
  • 메뉴를 키보드로 여는 Alt 리본 시퀀스와 선택하여 붙여넣기
  • 상대/절대/혼합 참조 4형태를 F4 한 방으로 순환시키는 법 (모델이 '복사해도 안 깨지는' 이유)
  • 이름정의로 가정을 관리하고, 감사 도구로 남의 모델(과 3개월 뒤 내 모델)을 추적하는 법
  • 마지막에는 마우스를 한 번도 쓰지 않고 미니 손익계산서 모델을 처음부터 세운다

Keywords: F2, F4, Ctrl+방향키, Alt sequence, Ctrl+Enter, 절대참조, 이름정의, Ctrl+[, 선택하여 붙여넣기, 데이터 표, 감사

⌨️ Windows 기준입니다. 재무모델링 업계 표준은 Windows 엑셀입니다. 이 가이드의 단축키도 Windows를 기준으로 씁니다. macOS를 쓰더라도 실무는 Windows 환경에서 익히길 강력히 권합니다(면접 실기·인턴 PC가 대부분 Windows). Mac 대응 키는 8장 뒤 표에 정리했습니다. 노트북이라면 Fn 조합으로 F키가 눌리는지 먼저 확인하세요.

1. 왜 마우스를 버리는가

먼저 철학. 마우스를 버리는 건 '멋'이 아니라 세 가지 실질 이득 때문이다.

① 속도. 마우스는 손을 홈 포지션에서 뗐다가 다시 갖다 놓는 왕복 비용이 있다. 셀 하나를 클릭할 때마다 0.5~1초가 새고, 모델 하나에 이 동작이 수백 번 쌓인다. 키보드는 손이 자판을 떠나지 않으므로 사고의 속도로 셀을 옮겨 다닐 수 있다.

② 정확성. 참조를 마우스로 드래그하면 한 칸씩 어긋나는 실수가 잦다. Ctrl+Shift+방향키로 범위를 잡으면 '데이터 끝까지'가 명확히 선택된다. 모델의 버그 상당수는 잘못 잡은 범위에서 나온다.

③ 리듬. 이게 가장 크다. 모델링은 "가정을 바꾸고 → 결과를 보고 → 다시 가정을 바꾸는" 반복이다. 키보드에 손을 얹은 채로 이 루프를 돌면 흐름이 끊기지 않는다. 흐름이 유지되면 실수를 덜 하고, 더 오래 집중한다.

원칙 0 — 손은 홈 포지션을 떠나지 않는다. 새로운 작업을 마우스로 하고 싶어질 때마다 "이걸 키보드로 하는 법이 있나?"를 먼저 물어라. 이 가이드의 목표는 그 질문에 대한 답을 근육에 새기는 것이다. 처음 2주는 오히려 느리다. 그 다음부터 마우스를 쓰던 자신으로 돌아갈 수 없게 된다.

학습법. 단축키는 '외우는' 게 아니라 '쓰다 보면 손에 붙는' 것이다. 오늘 이 페이지를 다 읽되, 실제 체득은 다음 라운드부터 모델을 짜면서 이 표를 옆에 띄워두고 하는 것으로 한다. 아래 Cheat Sheet를 인쇄하거나 별도 창에 띄워라.

2. 이동과 선택 — 시트 위를 날아다니기

모델링의 첫 근육은 '이동'이다. 수천 행짜리 재무 데이터 위에서 원하는 곳으로 즉시 가는 법.

🔑 Ctrl+방향키의 원리. "현재 셀부터 그 방향으로, 값이 있다↔없다가 바뀌는 경계까지" 점프한다. 데이터가 연속이면 표의 끝까지 한 방에 간다. 빈 셀에서 누르면 다음 데이터 시작점으로 간다. 이 경계 감각이 몸에 붙으면 스크롤을 쓸 일이 없다.

2.2 선택 (Selection)

선택은 이동에 Shift를 얹는 것이다. "이동 키 = 커서 하나만 감 / Shift 추가 = 지나온 자리를 다 칠함".

빈 시트에 아무 숫자나 5×5로 채워라. 그다음 마우스 없이: (1) Ctrl+Home으로 A1 복귀 → (2) Ctrl+Shift+End로 전체 블록 선택 → (3) 방향키로 선택 해제 후 Ctrl+↓로 데이터 바닥까지. 세 동작이 1초 안에 나올 때까지 반복.

3. 편집의 핵심 — F2와 입력 리듬

이동을 익혔으면 이제 '값을 넣고 고치는' 근육이다. 여기서 가장 중요한 키가 딱 하나 있다.

🔑 F2 — 셀 편집 모드. 셀을 선택한 상태에서 F2를 누르면 더블클릭과 똑같이 그 셀 안으로 커서가 들어가 수식을 고칠 수 있다. 마우스 더블클릭을 대체하는 단 하나의 키. 수식 안에서 참조가 어디를 가리키는지 색깔로 보여주기 때문에 검산할 때도 F2를 눌러 확인한다.

3.1 입력을 마치는 세 가지 방법

값을 입력한 뒤 어떤 키로 확정하느냐가 다음 커서 위치를 결정한다. 이 차이가 입력 '리듬'을 만든다.

모델링에서 Ctrl+D와 Ctrl+R은 절대적이다. 한 셀에 수식을 완성한 뒤, Ctrl+Shift+→로 채울 범위를 선택하고 Ctrl+R 한 방이면 연도별 추정이 오른쪽으로 쫙 퍼진다. — 단, 그 수식의 참조가 올바르게 고정돼 있어야 한다. 그게 5장의 주제다.

4. Alt 리본 시퀀스 — 메뉴를 키보드로 열기

단축키가 없는 기능은 어떻게 할까? 엑셀은 모든 리본 메뉴에 키보드 경로를 열어 뒀다. Alt를 한 번 누르면 리본 위에 알파벳 '키 팁'이 뜬다. 그 글자들을 순서대로 누르면 된다.

Alt 를 누르면 각 탭에 글자가 뜬다
Alt → H Home 탭 → O 서식(fOrmat) → I 열 너비 자동맞춤

이건 외우는 게 아니라 손이 기억하게 두는 것이다. 자주 쓰는 것 몇 개만 반복하면 저절로 붙는다. 대표적인 것들:

4.1 선택하여 붙여넣기 — 모델러의 필살기

모델링에서 "값만 붙여넣기", "수식만", "서식만", "행/열 바꿈"은 매일 쓴다. 마우스 우클릭 대신:

Ctrl+C 복사 → Ctrl+Alt+V 선택하여 붙여넣기 대화상자 → V 값만(Values) → Enter
Table 4.2. 선택하여 붙여넣기 옵션 (Ctrl+Alt+V 다음 누르는 글자)

값 붙여넣기 주의. "값만 붙여넣기"는 수식을 죽여 숫자로 박제한다. 편리하지만 모델에서는 신중하게 — 추정 로직이 있어야 할 자리에 값을 박아두면 나중에 가정을 바꿔도 그 셀만 안 움직인다(모델의 흔한 버그). 값 붙여넣기는 "외부에서 가져온 실적 데이터를 고정"할 때만 쓰고, 추정 영역엔 쓰지 않는다.

5. 참조 4형태와 F4 — 모델이 안 깨지는 이유

이 장이 R0의 진짜 핵심이다. 초심자 모델이 '복사하면 다 깨지는' 이유는 단 하나, 참조 고정을 모르기 때문이다. 이것만 확실히 잡으면 모델링의 절반은 끝난 셈이다.

5.1 상대참조 vs 절대참조

엑셀 참조에는 $ 기호로 표현하는 '고정'이 붙는다. 열 앞의 $는 열을, 행 앞의 $는 행을 고정한다.

Table 5.1. 참조 4형태
표기이름복사하면?
A1상대참조열·행 둘 다 따라 움직임
$A$1절대참조열·행 둘 다 고정 (안 움직임)
A$1혼합(행 고정)열은 움직이고 행만 고정
$A1혼합(열 고정)행은 움직이고 열만 고정

🔑 F4 — 참조 순환. 수식 편집 중(F2 상태) 참조 위에 커서를 두고 F4를 누를 때마다: A1 → $A$1 → A$1 → $A1 → 다시 A1 순으로 4형태가 순환한다. 마우스로 $를 일일이 칠 필요 없이 F4를 톡톡 눌러 원하는 고정 상태를 고른다.

5.2 왜 이게 모델의 생명인가

예를 들어 성장률 가정이 셀 $B$2에 있고, C열부터 연도별 매출을 추정한다고 하자. C10에 다음을 쓰면:

# C10 (2025년 매출) — 전년 매출 × (1 + 성장률)
=B10*(1+$B$2)

이걸 Ctrl+R로 오른쪽(D10, E10, ...)에 채우면: B10은 상대참조라 C10, D10으로 자연히 따라 움직여 '전년도'를 가리키고, $B$2는 절대참조라 모든 연도가 같은 성장률 가정 셀을 바라본다. 성장률을 B2에서 한 번 바꾸면 전 연도 추정이 동시에 갱신된다. — 이게 모델이 '살아있다'는 뜻이다.

실전 규칙. 가정(assumption)은 항상 한 곳에 모아 절대참조로 물고, 시계열로 흐르는 값(전년도 매출 등)은 상대참조로 둔다. 세로 방향으로 공통 헤더를 물 땐 A$1(행 고정), 가로 방향으로 공통 항목을 물 땐 $A1(열 고정)을 쓴다. 이 판단이 서면 어떤 셀이든 F4를 몇 번 눌러야 할지 즉시 안다.

🎯 손 풀기 2

B2에 성장률 0.08, B10에 매출 1000을 넣어라. C10에 위 수식을 F2로 입력하되 B2를 친 직후 F4를 눌러 $B$2로 만들어라. Enter 후 C10을 선택, Ctrl+Shift+→(G10까지)로 범위 잡고 Ctrl+R. 이제 B2를 0.15로 바꿔보라. 전 연도가 동시에 뛰면 성공.

6. 이름정의와 가정 관리

$B$2 대신 성장률이라는 이름을 셀에 붙이면 수식이 =B10*(1+성장률)이 된다. 읽기 쉽고, 실수도 준다. 이것이 이름정의(Named Range)다.

언제 이름을 쓰나. WACC, 세율, 영구성장률처럼 모델 전체에서 반복 참조하는 핵심 가정에만 이름을 붙여라. 모든 셀에 이름을 붙이면 오히려 관리가 안 된다. "이 숫자를 3개월 뒤의 내가 봤을 때 이름이 있으면 이해가 빠른가?"가 기준이다.

7. 표·자동합계·빠른채우기

7.1 자동 합계 — Alt =

합계를 낼 셀에서 Alt+=를 누르면 엑셀이 위(또는 왼쪽) 연속 범위를 자동으로 잡아 =SUM(...)을 제안한다. Enter로 확정. 손익계산서에서 비용 항목들을 더할 때 압도적으로 빠르다.

7.2 빠른 채우기 — Ctrl+E

패턴을 몇 개 보여주면 나머지를 알아서 채운다. 예: A열에 삼성전자(005930)가 있고 B열에 005930만 뽑고 싶다면, B1에 직접 005930을 치고 B2에서 Ctrl+E. 종목코드·계정명 정리 등 데이터 가공(R2)에서 강력하다.

7.3 엑셀 표 — Ctrl+T

데이터 범위를 '표'로 승격하면 구조적 참조(=[@매출]-[@비용])와 자동 확장·필터가 붙는다. 원자료를 다루는 R2에서 다시 본다. 지금은 "Ctrl+T로 표를 만든다"만 기억.

10. 실습 — 마우스 없이 미니 손익 모델 세우기

배운 걸 다 엮어보자. 목표: 마우스를 한 번도 쓰지 않고 3개년 매출·비용·영업이익을 추정하는 미니 모델. 아래 키스트로크를 그대로 따라 쳐라.

Step 1 — 가정 입력

Ctrl+Home A1로
A1에 가정 Enter → A2 매출성장률 / A3 원가율 입력, Tab으로 B열 이동
B2에 0.10 Enter 0.62 Enter (B3 원가율 62%)

Step 2 — 뼈대와 첫 해 실적

# 레이아웃 (행/열)
        C(2024)   D(2025)   E(2026)
7  매출    1000      =C7*(1+$B$2)  ...
8  매출원가 =C7*$B$3  =D7*$B$3      ...
9  매출총이익 =C7-C8  =D7-D8        ...

C7에 1000을 Enter. C8로 내려가 F2 없이 바로 =C7*를 치고, 원가율 B3을 친 뒤 F4로 $B$3 고정 → Enter. C9에서 Alt+= 대신 =C7-C8.

Step 3 — 추정 연도 채우기

D7에 =C7*(1+ B2 입력 후 F4 → $B$2 ) Enter
D7:D9 선택 후 Ctrl+C → E7:E9 선택 → Ctrl+V
또는 D7:E9 통째 선택 후 Ctrl+R 로 오른쪽 채우기

Step 4 — 검산

Ctrl+`로 수식을 펼쳐, 추정 셀에 하드코딩이 없는지 확인. E9(2026 매출총이익) 셀에서 Ctrl+[ 를 눌러 E7·E8을 거쳐 가정 셀 B2·B3까지 거슬러 올라가면 로직이 온전히 연결됐다는 뜻. 이제 B2를 0.20으로 바꿔 전 연도가 동시에 뛰면 모델 완성.

축하한다. 방금 마우스 없이 '살아있는' 모델을 지었다. 여기서 쓴 근육 — F2·F4·Ctrl+방향키·Ctrl+Enter·Ctrl+`·Ctrl+[ — 이 다음 라운드부터 3-statement 모델을 지을 때 그대로 쓰인다. R1에서는 이 위에 회계의 뼈대를 얹는다.

Quiz — 셀프 체크 10문항

Q1. C10의 =B10*(1+$B$2)를 D10으로 복사하면 수식은?
=C10*(1+$B$2). 상대참조 B10은 한 칸 오른쪽 C10으로 따라가고, 절대참조 $B$2는 그대로 고정된다.
Q2. 여러 셀을 선택한 상태에서 수식을 타이핑하고 한 번에 채우려면 무슨 키로 확정?
Ctrl+Enter. 선택된 모든 셀에 상대참조가 각 위치에 맞게 채워진다. (그냥 Enter는 한 셀만 채우고 아래로 이동)
Q3. F4를 수식 편집 중 참조 위에서 세 번 누르면 A1은 어떤 형태가 되나?
1번=$A$1, 2번=A$1, 3번=$A1. 순환 순서는 절대 → 행고정 → 열고정 → (4번째) 다시 상대.
Q4. 최종 목표주가 셀이 어떤 셀들로부터 계산됐는지 거슬러 올라가는 키는?
Ctrl+[ (참조하는 셀로 이동). 되돌아올 땐 F5 → Enter.
Q5. 수식 결과를 값으로 박제(하드코딩)하는 키 순서는? 그리고 모델링에서 왜 조심해야 하나?
Ctrl+C → Ctrl+Alt+V → V → Enter. 추정 영역에 값을 박으면 가정을 바꿔도 그 셀만 안 움직여 모델이 조용히 깨진다. 외부 실적 데이터 고정에만 사용.
Q6. 연속된 재무 데이터의 맨 아래 행으로 스크롤 없이 가려면?
Ctrl+↓. 데이터가 끊기는 마지막 셀로 점프. 범위째 선택하려면 Ctrl+Shift+↓.
Q7. 시트 전체 셀의 '값 대신 수식'을 한 번에 보이게/숨기게 하는 토글 키는?
Ctrl+` (숫자 1 왼쪽의 백틱). 하드코딩·오류 로직을 찾는 감사에 필수.
Q8. 성장률 가정을 여러 연도가 공통으로 물게 하려면 절대참조를 써야 한다. 반대로 '전년도 매출'은 왜 상대참조여야 하나?
각 연도가 '자기 바로 왼쪽(전년도)'을 가리켜야 하므로, 복사할 때 참조가 함께 움직여야 한다. 고정하면 모든 연도가 같은 과거 셀을 물어 추정이 무너진다.
Q9. 손익계산서에서 비용 항목 여러 개의 합을 내는 가장 빠른 키는?
합계 셀에서 Alt+= → Enter. 위 연속 범위를 자동으로 SUM으로 잡아준다.
Q10. Mac에서 Windows의 F4(참조 순환)에 해당하는 키는?
⌘+T. 다만 Mac은 Alt 리본 시퀀스가 없어, 실무 모델링은 Windows에서 익히는 편이 유리하다.
