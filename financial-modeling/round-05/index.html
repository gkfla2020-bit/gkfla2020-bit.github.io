3-Statement 모델 II — BS·CF 연결과 순환참조

세 표를 맞물려 돌리고, 대차를 0으로 닫는 완결 모델
Reference: Wall Street Prep · BIWS Financial Modeling · 현직 IB/리서치 3-statement 컨벤션
Overall Progress: 5/12 Rounds
이 라운드에서 만드는 것

R4에서 손익계산서(IS)는 끝냈다. 매출부터 순이익까지, 가정을 바꾸면 살아 움직이는 IS가 손에 있다. 하지만 그건 세 표 중 하나일 뿐이다. 진짜 모델은 IS·BS·CF 세 표가 서로를 물고 도는 구조다. 순이익은 이익잉여금으로 흘러 BS를 밀고, 유형자산·운전자본은 현금흐름을 결정하고, 그 현금은 다시 BS의 자산 맨 위로 돌아온다. 이 라운드에서는:

  • 유형자산을 롤포워드로 굴린다 — 기초 + CAPEX − 감가상각 = 기말
  • 매출채권·재고·매입채무를 회전일수(DSO/DIO/DPO)로 추정하고, 운전자본 증감이 현금에 미치는 방향을 몸에 새긴다
  • 이익잉여금·차입금을 롤포워드로 닫고, 이자비용 = 차입금 × 이자율을 연결한다
  • 간접법 현금흐름표를 영업·투자·재무 3구획으로 조립해 기말현금을 산출한다
  • 기말현금을 BS 자산에 물려 대차(자산=부채+자본)를 0으로 닫고, 안 맞을 때의 디버깅 순서를 익힌다
  • 이자 → 순이익 → 현금 → 차입금 → 이자로 도는 순환참조를 이해하고 반복계산으로 푼다

Keywords: 롤포워드, CAPEX, 감가상각, 순운전자본, DSO/DIO/DPO, 이익잉여금, revolver, 간접법 CF, 대차일치, 순환참조, 반복계산, circuit breaker

⚠️ 이 라운드는 커리큘럼에서 가장 어렵다. R4까지가 '한 표를 잘 짓는 법'이었다면, R5는 '표들이 서로를 물게 하는 법'이다. 한 셀만 잘못 물려도 대차가 안 맞고, 순환참조가 걸리면 모델 전체가 #REF! 없이도 조용히 틀린다. 서두르지 말고 롤포워드 → CF 조립 → BS 닫기의 순서를 통째로 이해한 뒤 손을 대라. 각 장을 R4에서 만든 모델 위에 얹는다고 생각하면 된다.

1. 이번 라운드의 목표 — 세 표를 맞물리기

R4에서 우리는 손익계산서를 완성했다. 하지만 손익계산서는 "얼마 벌었나"만 말한다. "그 돈이 어디에 쌓였나(BS)"와 "실제로 현금이 얼마나 들어왔나(CF)"는 아직 비어 있다. 이 세 표를 하나로 엮어야 비로소 '모델'이다.

세 표는 다음처럼 물린다. IS의 순이익은 두 곳으로 흐른다 — 하나는 BS의 이익잉여금으로(누적 자본 증가), 다른 하나는 CF의 영업활동 출발점으로. CF는 순이익에서 시작해 비현금 항목(감가상각)과 운전자본 증감, 투자(CAPEX), 재무(차입·배당)를 반영해 순현금증감을 낸다. 그 순현금증감을 기초현금에 더하면 기말현금이 나오고, 이 기말현금이 다시 BS 자산의 맨 위로 돌아온다. 원이 닫힌다.

🔑 모델의 두 가지 자기검증. 세 표가 올바로 물렸다면 두 등식이 자동으로 성립한다. ① BS 대차 일치: 자산 = 부채 + 자본 (좌우 차이 = 0). ② 현금 일치: CF의 기말현금 = BS의 현금 계정. 이 둘이 맞으면 모델이 정합적이라는 강력한 신호고, 안 맞으면 어딘가 연결이 끊겼다는 경보다. 이 두 등식이 R5 전체의 나침반이다.

작업 순서. 이번 라운드의 물리적 순서는 이렇다 — (1) 유형자산·감가상각 롤포워드, (2) 운전자본 스케줄, (3) 이익잉여금·차입금 롤포워드, (4) 이 조각들을 CF로 조립, (5) CF의 기말현금을 BS에 물려 대차 확인, (6) 이자 순환 해결. 앞 조각이 없으면 뒤 표를 못 짓는다. 아래 장들은 정확히 이 순서를 따른다.

2. 감가상각·유형자산·CAPEX — 첫 번째 롤포워드

모델링에서 가장 자주 쓰는 패턴이 롤포워드(roll-forward)다. "기초 잔액 + 늘어난 것 − 줄어든 것 = 기말 잔액". 유형자산(PP&E)이 그 대표다.

\[ \text{기말 순유형자산} = \text{기초 순유형자산} + \text{CAPEX} - \text{감가상각비} \]

CAPEX(자본적 지출)는 그 해에 새로 투자한 유형자산이다(현금 유출 → CF 투자활동으로). 감가상각비는 기존 자산이 그 해에 닳은 비용이다(IS의 비용이자, 현금이 나가지 않는 비현금 비용). 이 둘이 유형자산 잔액을 밀고 당긴다.

2.1 가정 잡기

CAPEX는 보통 매출 대비 %로 추정한다(예: 매출의 5%). 감가상각비는 (a) 기초 유형자산 대비 %로 단순 추정하거나, (b) 자산 취득연도별로 내용연수에 걸쳐 나누는 감가상각 스케줄을 따로 짠다. 초·중급 모델은 (a)로 충분하다.

Table 2.1. 유형자산 롤포워드 (단위: 억원)
항목2025E2026E2027E
기초 순유형자산1,0001,0501,103
(+) CAPEX (매출의 5%)150158165
(−) 감가상각비(100)(105)(110)
기말 순유형자산1,0501,1031,158
# 유형자산 롤포워드 (C=2025E, D열은 =C의 기말을 기초로)
# C: 기초=전년 기말, CAPEX=매출*capex율, 감가=기초*감가율
C10 # 기초 순PP&E  =B_기말PPE
C11 # CAPEX       =C_매출*$capex율
C12 # 감가상각비   =-C10*$감가율
C13 # 기말 순PP&E  =C10+C11+C12
D10 # 다음해 기초  =C13   # ← 기말이 다음해 기초로 흐른다

🔑 롤포워드의 심장은 "기말 → 다음해 기초" 연결이다. D10 = C13 이 한 줄이 시계열을 잇는다. 이 연결만 상대참조로 옳게 물려 두면 Ctrl+R로 오른쪽에 쫙 채워도 각 해가 전년 기말을 자동으로 물어 온다. CAPEX율·감가율 같은 가정은 $로 절대 고정(R0 5장 복습).

감가상각비는 세 표를 동시에 건드린다. IS에서는 비용(순이익을 깎음), BS에서는 유형자산을 줄임, CF에서는 순이익에 도로 더해진다(현금이 안 나갔으니까). 하나의 숫자가 세 곳에 나타나되, 각 표에서 부호와 역할이 다르다. 이 '한 숫자, 세 얼굴'을 이해하는 게 3-statement의 핵심 감각이다.

3. 순운전자본(NWC) — 현금을 갉아먹거나 풀어주는 것

순운전자본(Net Working Capital)은 영업에 묶인 단기 자산·부채다. 핵심 3인방: 매출채권(팔았지만 아직 못 받은 돈), 재고자산(안 팔린 물건), 매입채무(샀지만 아직 안 준 돈).

\[ \text{NWC} = \text{매출채권} + \text{재고자산} - \text{매입채무} \]

3.1 회전일수로 추정하기

이 세 항목은 매출·매출원가에 연동된다. 가장 실무적인 추정법이 회전일수(days)다.

Table 3.1. 운전자본 회전일수 공식
지표뜻추정 공식(잔액 역산)
DSO (매출채권회전일)파는 데서 돈 받기까지 며칠매출채권 = 매출 × DSO / 365
DIO (재고회전일)재고가 팔릴 때까지 며칠재고 = 매출원가 × DIO / 365
DPO (매입채무회전일)사고서 돈 주기까지 며칠매입채무 = 매출원가 × DPO / 365

과거 재무제표에서 각 회전일수를 역산해(예: DSO = 매출채권 / 매출 × 365) 그 값을 추정연도에 가정으로 고정한 뒤, 위 공식을 뒤집어 미래 잔액을 뽑는다. 매출·매출원가는 R4 IS에서 이미 추정돼 있으니 잔액이 자동으로 따라 나온다.

# NWC 잔액 추정 (C열=2025E)
C_매출채권  =C_매출  *$DSO/365
C_재고     =C_매출원가*$DIO/365
C_매입채무  =C_매출원가*$DPO/365
C_NWC     =C_매출채권+C_재고-C_매입채무

3.2 NWC 증감이 현금에 미치는 방향 — 여기서 다 헷갈린다

🔑 NWC가 늘면 현금은 나간다. NWC가 줄면 현금이 들어온다. 직관: 매출채권이 늘었다는 건 '팔았는데 돈은 아직 안 들어온' 상태 → 그만큼 현금이 묶임 → 현금 유출. 매입채무가 늘었다는 건 '샀는데 돈은 아직 안 준' 상태 → 그만큼 현금을 아낌 → 현금 유입. 그래서 CF에서 운전자본 증감은 −(당기 NWC − 전기 NWC) = −ΔNWC로 들어간다.

\[ \text{CF의 운전자본 효과} = -\,\Delta \text{NWC} = -\,(\text{NWC}_t - \text{NWC}_{t-1}) \]
Table 3.2. NWC 변화와 현금 방향 (부호 정리)
항목증가하면CF 부호
매출채권 ↑돈이 묶임현금 유출 (−)
재고자산 ↑돈이 묶임현금 유출 (−)
매입채무 ↑지급을 미룸현금 유입 (+)

부호 실수 1순위. 자산성 항목(매출채권·재고)은 늘면 현금 유출, 부채성 항목(매입채무)은 늘면 현금 유입 — 방향이 반대다. NWC를 매출채권+재고−매입채무로 하나로 묶어 두면 −ΔNWC 한 줄로 부호가 자동 처리되니, 항목별로 따로 부호를 매기다 틀리지 말고 NWC 총액을 굴려라.

4. 이익잉여금·자본 — 순이익이 쌓이는 곳

IS의 순이익은 한 번 벌고 사라지지 않는다. 배당으로 나간 만큼을 빼고 이익잉여금(retained earnings)에 누적된다. 이것도 롤포워드다.

\[ \text{기말 이익잉여금} = \text{기초 이익잉여금} + \text{순이익} - \text{배당} \]
# 이익잉여금 롤포워드 (C=2025E)
C_기초이익잉여금  =B_기말이익잉여금
C_순이익        =C_IS순이익          # ← IS에서 링크
C_배당         =-C_순이익*$배당성향  # 배당성향 가정
C_기말이익잉여금  =C_기초+C_순이익+C_배당
D_기초이익잉여금  =C_기말이익잉여금      # 다음해 기초로

자본(equity) 전체는 보통 자본금 + 자본잉여금 + 이익잉여금으로 구성된다. 자본금·자본잉여금은 유상증자·자사주 같은 이벤트가 없으면 대개 전년 값 그대로 흐른다(상수 유지). 즉 자본에서 매년 실질적으로 움직이는 건 이익잉여금뿐인 경우가 많다.

배당은 재무활동 현금유출이기도 하다. 배당은 이익잉여금을 깎는 동시에 CF의 재무활동에서 현금유출로 잡힌다. 감가상각처럼 여기서도 '한 숫자가 두 표에' 나타난다 — 배당 가정 셀 하나를 이익잉여금 롤포워드와 CF 재무활동 두 곳이 함께 물게 해야 정합성이 유지된다.

5. 차입금·이자 — 순환의 씨앗

부채 쪽 롤포워드는 차입금이다. 그리고 여기서 이자비용이 나오는데, 이 이자가 8장 순환참조의 씨앗이 된다.

\[ \text{기말 차입금} = \text{기초 차입금} + \text{신규 차입} - \text{상환} \]

5.1 이자비용 — 평잔에 곱한다

🔑 이자비용 = 차입금(평잔) × 이자율. 평잔(평균잔액)은 (기초 차입금 + 기말 차입금) / 2다. 기말 잔액만 쓰지 않고 평잔을 쓰는 이유는 그 해 중간에 차입·상환이 일어나므로 평균이 더 정확하기 때문이다. 그런데 기말 차입금은 그 해 현금이 부족한지에 달려 있고, 현금 부족 여부는 이자비용에 달려 있다. — 여기서 순환이 시작된다(8장에서 정면돌파).

# 이자비용 = 평잔 × 이자율
C_평균차입금  =(C_기초차입금+C_기말차입금)/2
C_이자비용   =-C_평균차입금*$이자율   # ← 기말차입금을 물면 순환 발생

5.2 Revolver — 현금 부족 시 자동 조달

모델을 돌리다 보면 현금이 마이너스로 떨어지는 해가 생긴다. 실무 모델은 여기에 revolver(단기 회전차입)를 둔다. "현금이 최소 유지선 아래로 떨어지면 부족분만큼 자동으로 단기차입을 일으키고, 현금이 남으면 우선 상환하는" 스위치다.

# revolver 개념 (현금 최소유지선=$min현금)
# revolver 인출 = MAX(0, 최소현금 - revolver 전 현금)
C_revolver인출 = MAX(0, $min현금 - C_revolver전현금)
# revolver가 늘면 → 차입금↑ → 이자↑ → 순이익↓ → 현금↓ → …다시 revolver (순환!)

revolver는 순환참조를 강하게 만든다. 개념만 이해하고, 실제 배선은 8장에서 반복계산을 켠 뒤에 하라. revolver 없이 '고정 차입 스케줄'만 쓰면 순환이 이자 ↔ 순이익 고리로 약하게만 걸리고, revolver를 넣으면 현금 ↔ 차입 고리까지 얹혀 순환이 굵어진다. 초급 모델은 revolver를 빼고 시작하는 걸 권한다.

6. 현금흐름표 조립(간접법) — 순이익에서 기말현금까지

이제 앞에서 만든 조각(순이익·감가상각·ΔNWC·CAPEX·차입·배당)을 간접법 현금흐름표로 조립한다. 간접법은 순이익에서 출발해 현금과 회계이익의 차이를 조정한다.

Table 6.1. 간접법 현금흐름표 구조
구획구성출처
영업활동순이익 (+)감가상각 (±)−ΔNWCIS + 2장 + 3장
투자활동−CAPEX2장 유형자산
재무활동(±)차입 순증감 (−)배당5장 + 4장
\[ \text{순현금증감} = \text{영업} + \text{투자} + \text{재무} \qquad \text{기말현금} = \text{기초현금} + \text{순현금증감} \]
# 간접법 CF (C=2025E)
## 영업활동
C_순이익     =C_IS순이익
C_감가상각    =-C_감가상각비셀      # IS에선 (-)비용, CF에선 (+)로 되돌림

## 재무활동

## 합산
C_순현금증감  =C_영업CF+C_투자CF+C_재무CF
C_기초현금    =B_기말현금
C_기말현금    =C_기초현금+C_순현금증감

부호 규칙 하나로 통일하라. "현금이 들어오면 (+), 나가면 (−)". 감가상각은 IS에서 뺐던 비현금 비용이니 (+)로 되돌리고, CAPEX·배당은 현금이 나가니 (−), NWC는 −ΔNWC. 이 규칙만 지키면 영업+투자+재무를 그냥 Alt+=로 더해도 부호가 맞는다.

7. BS 닫기와 대차 검증 — 0으로 만드는 순간

CF에서 나온 기말현금을 BS 자산의 현금 계정에 물린다. 그러면 자산 쪽이 완성되고, 부채·자본 쪽은 앞서 만든 롤포워드(매입채무·차입금·이익잉여금 등)로 이미 채워져 있다. 이제 좌우를 더해 비교한다.

\[ \text{대차 차이(Check)} = \text{총자산} - (\text{총부채} + \text{총자본}) \overset{?}{=} 0 \]
# BS 자산: 현금은 CF에서 링크
C_BS현금  =C_CF기말현금        # ← CF와 BS를 잇는 결정적 한 줄
C_총자산  =C_BS현금+C_매출채권+C_재고+C_기말순PPE+...
C_총부채자본 =C_매입채무+C_기말차입금+C_자본금+C_기말이익잉여금+...
# 검증 셀 (반드시 0이어야 함)
C_Check  =C_총자산-C_총부채자본   # = 0 이면 모델 정합
Model Anchor · 대차일치
대차 차이 = 0 은 모델 정합성의 최종 신호다

3-statement 모델에서 대차일치(자산 = 부채 + 자본, 차이 0)는 단순한 회계 규칙이 아니라 모든 연결이 올바로 물렸다는 증거다. 순이익이 이익잉여금과 CF 양쪽으로 정확히 흘렀고, 감가상각·NWC·CAPEX가 세 표에서 부호를 맞춰 반영됐고, 기말현금이 CF에서 BS로 정확히 링크됐을 때에만 좌우가 저절로 맞는다. 그래서 실무 모델은 별도 Check 행을 두고 항상 0인지 감시한다. Check가 0에서 벗어나는 순간 = 어딘가 연결이 끊긴 순간이다. 이 한 셀이 모델 전체의 건강검진표다.

7.1 대차가 안 맞을 때 디버깅 순서

Check가 0이 아니면 당황하지 말고 순서대로 좁혀라. 차이 금액 자체가 힌트인 경우가 많다.

  1. 차이 금액을 다른 셀과 대조. 차이가 정확히 배당액·CAPEX·ΔNWC와 같으면 그 항목이 한쪽 표에만 반영됐다는 뜻이다(가장 흔한 원인).
  2. 부호 점검. 배당·CAPEX·NWC증감이 (−)여야 할 자리에 (+)로 들어갔는지. 차이가 정확히 두 배면 부호 뒤집힘이 유력.
  3. 기초=전년기말 연결 확인. 롤포워드의 기초 = 전년 기말 링크가 한 해라도 끊기면 그 해부터 대차가 무너진다.
  4. 과거 실적 열부터 확인. 추정 이전, 실적으로 채운 열에서 이미 Check≠0이면 링크가 아니라 입력 자체가 틀린 것.
  5. 감사 단축키로 추적. Check 셀에서 Ctrl+[ 로 총자산·총부채자본을 거쳐 근원까지 거슬러 올라간다(R0 8장).

🔍 "한 해만 안 맞나, 그 뒤로 다 안 맞나"를 먼저 봐라. 특정 해부터 갑자기 어긋나면 그 해에 새로 넣은 항목이 범인이다. 첫 추정연도부터 어긋나면 실적→추정 연결부가 의심된다. 대차 오류는 대부분 '두 표에 반영돼야 할 항목이 한 표에만' 들어갔거나 '부호'거나 '기초-기말 링크 끊김', 이 셋 중 하나다.

8. 순환참조(Circular Reference) — 이자가 만드는 고리

5장에서 예고한 순환이다. 고리를 눈으로 따라가 보자.

\[ \text{이자비용} \to \text{순이익} \to \text{현금} \to \text{차입금(revolver)} \to \text{이자비용} \to \cdots \]

이자비용은 평잔 차입금에 달려 있고 → 이자비용이 순이익을 깎고 → 순이익이 CF를 통해 현금을 바꾸고 → 현금 부족이면 revolver로 차입금이 늘고 → 늘어난 차입금이 다시 이자비용을 키운다. 셀이 자기 자신을 (몇 단계 건너) 참조하는 순환참조다. 엑셀은 기본적으로 이걸 오류로 보고 0 또는 경고를 낸다.

8.1 반복계산(Iterative Calculation) 켜기

이 순환은 '버그'가 아니라 회계적으로 실재하는 관계다. 그래서 엑셀에게 "빙글빙글 돌려서 수렴할 때까지 계산하라"고 허락한다.

File → Options → Formulas → Enable iterative calculation 체크
Maximum Iterations 100 / Maximum Change 0.001 정도로

반복계산을 켜면 엑셀이 값을 넣고→다시 계산하고→또 넣기를 반복해 변화가 임계값 아래로 떨어질 때(수렴)까지 돌린다. 이자↔순이익 순환은 몇 번의 반복으로 안정적으로 수렴한다.

⚠️ 순환참조의 위험 — 반드시 알아라. 반복계산을 켜면 편리하지만 대가가 있다. ① 오류가 전염된다. 순환 고리 안 어딘가에서 한 번 #DIV/0!나 #REF!가 나면, 반복이 그 오류를 온 모델에 퍼뜨려 되돌리기 어려워진다. ② 수렴이 깨질 수 있다. 가정을 극단으로 바꾸면 값이 발산하거나 진동한다. ③ 디버깅이 힘들다. 값이 계속 미세하게 흔들려 추적이 어렵다. 그래서 실무는 반드시 circuit breaker(회로 차단 스위치)를 함께 둔다.

8.2 Circuit Breaker — 순환을 끊는 스위치

circuit breaker는 셀 하나(예: $차단에 1 또는 0)를 두고, 순환 고리의 이자 계산을 이 스위치로 감싸는 방법이다. 모델이 오류로 오염되면 스위치를 켜서 순환을 강제로 끊고→오류를 청소한 뒤→다시 스위치를 꺼서 순환을 되살린다.

# circuit breaker: $차단=1이면 이자를 0으로 끊어 순환 차단
C_이자비용 = IF($차단=1, 0, -C_평균차입금*$이자율)
# 오류 발생 시: $차단=1 → 순환 끊김 → 오류 소멸 → $차단=0 복귀

🔑 순환 대응 3단 세트. (1) File>Options>Formulas에서 반복계산 ON, (2) 이자 셀을 circuit breaker IF로 감싸기, (3) 오류가 나면 스위치 1→청소→0. 이 셋이 순환참조를 '무섭지 않게' 다루는 표준 절차다. 순환을 아예 피하고 싶으면 이자를 기초 차입금(평잔 대신)에만 걸어 고리를 끊는 단순화도 가능하다 — 정확도를 조금 내주고 순환을 없앤다.

9. 실전 워크스루 — 키보드만으로 BS·CF 연결하기

이제 R4 모델 위에 BS·CF를 얹는 전 과정을 키스트로크로 밟는다. 마우스는 여전히 책상 밖이다.

Step 1 — 과거 실적 연결 (링크)

BS/CF 시트로 Ctrl+PgDn 이동
현금 실적 셀에서 = → Ctrl+PgUp 데이터 시트로 → 해당 셀 클릭 대신 Ctrl+방향키 로 이동 후 Enter
과거 열에서 먼저 Check 셀이 0인지 확인 (실적부터 대차 맞아야)

Step 2 — 롤포워드 배선 (기말 → 다음해 기초)

첫 추정열 유형자산 기초에서 = ←전년기말셀 Enter
CAPEX·감가·기말까지 한 열 완성 후 열 전체 선택 Ctrl+Shift+↓
이익잉여금·차입금도 같은 방식으로 기초=전년기말 링크 → Ctrl+R 로 우측 연도 채우기

Step 3 — CF 조립 → 기말현금 → BS 현금

영업CF 합계 셀에서 Alt+= 순이익+감가+NWC증감 자동합 Enter

Step 4 — 대차 맞추기 & 순환 켜기

Check 셀 =총자산-총부채자본 → 0 아니면 Ctrl+[ 로 근원 추적
이자를 평잔에 걸면 순환 → File Options Formulas 반복계산 ON
이자 셀을 circuit breaker IF($차단,0,…) 로 감싼다

완성. Check가 전 연도 0이고, CF 기말현금 = BS 현금이면 세 표가 맞물려 도는 3-statement 모델이 완성된 것이다. 이제 성장률·CAPEX율·이자율 같은 가정 셀 하나를 바꾸면 IS→BS→CF가 동시에 재계산되며 Check는 여전히 0을 유지한다 — 이게 '살아있는' 완결 모델이다. R6에서는 이 모델에서 뽑은 잉여현금흐름(FCF)으로 DCF를 돌려 목표주가를 낸다.

🎯 이번 주 과제

R4에서 만든 IS 모델 위에 (1) 유형자산·이익잉여금·차입금 롤포워드 3종을 얹고, (2) DSO/DIO/DPO로 NWC 스케줄을 짜고, (3) 간접법 CF를 조립해 (4) Check 행이 3개 추정연도 모두 0이 되게 만들어라. 마지막으로 이자를 평잔에 걸어 순환을 일으킨 뒤 반복계산을 켜서 수렴시키고, circuit breaker를 달아라. 대차가 안 맞으면 7.1의 디버깅 순서를 그대로 밟아라 — 차이 금액이 어떤 항목과 같은지부터 봐라.

Quiz — 셀프 체크 10문항

Q1. 유형자산 롤포워드 공식을 쓰고, '기말 → 다음해 기초' 연결이 왜 상대참조여야 하는지 설명하라.
기말 순유형자산 = 기초 + CAPEX − 감가상각비. D_기초 = C_기말 링크는 각 해가 '자기 바로 전년의 기말'을 물어야 하므로 복사 시 참조가 함께 움직여야 한다(상대참조). 고정하면 모든 해가 같은 과거 기말을 물어 시계열이 무너진다.
Q2. 감가상각비가 세 표(IS·BS·CF)에서 각각 어떤 역할·부호로 나타나는가?
IS: 비용(−, 순이익을 깎음). BS: 유형자산을 줄임. CF: 비현금 비용이므로 영업활동에서 순이익에 (+)로 되돌려 더함. 한 숫자, 세 얼굴.
Q3. DSO 25일, 매출이 3,650억이면 매출채권 추정 잔액은?
매출채권 = 매출 × DSO / 365 = 3,650 × 25 / 365 = 250억.
Q4. 매출채권이 늘면 현금은 유입인가 유출인가? 매입채무가 늘면?
매출채권 ↑ = 팔았는데 돈 못 받음 = 현금 유출(−). 매입채무 ↑ = 샀는데 지급 미룸 = 현금 유입(+). CF에는 NWC를 묶어 −ΔNWC로 넣으면 부호가 자동 처리된다.
Q5. 기초 이익잉여금 500, 순이익 120, 배당성향 30%일 때 기말 이익잉여금은?
배당 = 120 × 30% = 36. 기말 = 500 + 120 − 36 = 584.
Q6. 이자비용을 기말 차입금이 아니라 '평잔'에 거는 이유는? 평잔 공식은?
그 해 중간에 차입·상환이 일어나므로 평균잔액이 더 정확하다. 평잔 = (기초 차입금 + 기말 차입금) / 2. 다만 기말 차입금을 물면 순환참조가 발생한다.
Q7. 간접법 CF의 세 구획과 각 구획의 대표 구성 항목을 말하라.
영업(순이익 + 감가상각 ± −ΔNWC) / 투자(−CAPEX) / 재무(차입 순증감 − 배당). 세 구획 합 = 순현금증감, 기초현금 + 순현금증감 = 기말현금.
Q8. 모델 정합성의 두 자기검증 등식은 무엇인가?
① BS 대차 일치: 총자산 = 총부채 + 총자본 (Check = 0). ② 현금 일치: CF 기말현금 = BS 현금 계정. 둘 다 맞으면 세 표가 올바로 물린 것.
Q9. 순환참조 고리를 순서대로 나열하고, 반복계산은 어디서 켜는가?
이자비용 → 순이익 → 현금 → 차입금(revolver) → 이자비용 → … File > Options > Formulas > Enable iterative calculation 체크(Max Iterations·Max Change 설정).
Q10. 대차 Check가 정확히 배당액만큼 어긋났다. 가장 유력한 원인은?
배당이 한쪽 표에만 반영됐다는 뜻 — 이익잉여금 롤포워드에서는 뺐는데 CF 재무활동에 안 넣었거나(그 반대). '두 표에 들어가야 할 항목이 한 표에만' 들어간 전형적 오류. 차이 금액이 특정 항목과 같으면 그 항목부터 의심하라.
