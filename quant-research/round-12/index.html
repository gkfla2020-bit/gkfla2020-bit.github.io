1. 좋은 리서치 질문 — 프로젝트의 90%는 질문에서 결정된다

초보 리서처가 가장 많이 하는 실수는 "일단 데이터를 받아서 이것저것 돌려보는 것"이다. 이러면 결과가 나와도 "그래서 뭘 물어본 거였지?"라는 상태가 된다. 리서치는 질문에서 시작한다. 질문이 나쁘면 아무리 정교한 방법을 써도 결과가 의미 없다.

Definition 1.1 — 좋은 리서치 질문의 3조건

  1. 검증 가능(falsifiable) — 데이터로 "예/아니오"를 판정할 수 있어야 한다. "이 팩터가 좋은가?"는 나쁘다. "GP/A 상위 30% 포트폴리오가 하위 30% 대비 월 0을 넘는 초과수익을 내는가?"는 좋다.
  2. 데이터 확보 가능(available) — 필요한 데이터를 실제로 구할 수 있어야 한다. "내부자 실시간 매매를 예측할 수 있는가?"는 데이터가 없어 불가능하다.
  3. 경제적 직관 존재(economic rationale) — 왜 이 관계가 성립해야 하는지 사전에 설명할 수 있어야 한다. 직관 없이 데이터만 뒤지면 다중검정 편향(data snooping)에 빠진다.

세 조건을 한 문장으로 요약하면: "측정 가능한 결과 + 구할 수 있는 데이터 + 미리 세운 가설." 이 셋이 모두 있어야 결과가 나왔을 때 "이게 진짜인지 우연인지"를 논할 수 있다.

함정 — HARKing (Hypothesizing After the Results are Known): 결과를 본 뒤에 가설을 지어내는 것. 100개 팩터를 돌려서 t=2.5짜리 하나를 찾은 뒤 "나는 원래 이 팩터가 될 줄 알았다"고 쓰는 것이 대표적이다. 이러면 사후적으로는 그럴듯하지만, 실제로는 우연을 실력으로 포장한 것이다. 면접관은 이걸 귀신같이 잡아낸다. 가설은 데이터를 보기 전에 글로 적어둔다.

1.1 나쁜 질문 → 좋은 질문: 5가지 변환

추상적인 규칙보다 예시가 빠르다. 아래 다섯 쌍을 비교하면서, 무엇이 질문을 "검증 가능하게" 만드는지 감을 잡자.

Table 1.1. 나쁜 질문을 좋은 질문으로 고치기

공통 패턴이 보이는가? 좋은 질문은 항상 유니버스, 기간, 변수 정의, 비교 대상, 판정 기준을 못 박는다. 나쁜 질문은 이 다섯 개가 전부 비어 있다. 질문을 쓸 때 이 다섯 칸을 채우는 연습을 하면 자연히 좋은 질문이 된다.

\[ \text{좋은 질문} = \underbrace{U}_{\text{universe}} \times \underbrace{[t_0, t_1]}_{\text{period}} \times \underbrace{f(\cdot)}_{\text{variable def}} \times \underbrace{H_0}_{\text{null}} \times \underbrace{\tau}_{\text{decision rule}} \]

↑ 리서치 질문은 다섯 요소의 곱이다. 유니버스 U, 기간 구간, 변수 정의 함수 f, 귀무가설 H₀, 그리고 판정 임계값 τ(예: "샤프 > 0.5" 또는 "t > 2"). 하나라도 비면 결과를 해석할 수 없다.

# 리서치 질문을 코드로 "고정"하는 습관 — 실험 명세를 dataclass로
from dataclasses import dataclass, field
import datetime as dt

@dataclass(frozen=True)
class ResearchSpec:
    universe: str                 # "KOSPI200"
    start: dt.date
    end: dt.date
    signal_def: str               # "GP/A = (revenue - COGS) / total_assets"
    null_hypothesis: str          # "H0: 롱숏 α = 0"
    decision_rule: str            # "거래비용 30bp 차감 후 α의 t > 2"
    rebalance: str = "monthly"
    cost_bps: float = 30.0

spec = ResearchSpec(
    universe="KOSPI200",
    start=dt.date(2010, 1, 1), end=dt.date(2023, 12, 31),
    signal_def="GP/A = (revenue - COGS) / total_assets, 4분기 롤링",
    null_hypothesis="H0: Quality 롱숏 포트폴리오의 FF5 알파 = 0",
    decision_rule="비용 30bp 후 알파 t-stat > 2, OOS 2019~2023 유지",
)
print(spec)
Output: ResearchSpec(universe='KOSPI200', start=datetime.date(2010, 1, 1), end=datetime.date(2023, 12, 31), signal_def='GP/A = (revenue - COGS) / total_assets, 4분기 롤링', null_hypothesis='H0: Quality 롱숏 포트폴리오의 FF5 알파 = 0', decision_rule='비용 30bp 후 알파 t-stat > 2, OOS 2019~2023 유지', rebalance='monthly', cost_bps=30.0)

1.2 경제적 직관이 왜 "데이터보다 먼저"인가

세 조건 중 초보가 가장 무시하는 것이 경제적 직관이다. "데이터가 유의하면 됐지, 왜 굳이 이유를 미리 대야 하나?"라고 생각하기 쉽다. 답은 통계적 검정력의 회계에 있다.

사전 가설이 하나면, 그 하나만 검정하므로 t>2(5% 유의)가 정당하다. 그러나 직관 없이 데이터를 뒤지면, 사실상 눈에 보이지 않게 수십~수백 개를 시도한 것이다. 아래 식이 그 대가를 보여준다.

\[ P(\text{적어도 하나 위양성}) = 1 - (1-\alpha)^{N} \xrightarrow{\;\alpha=0.05,\,N=20\;} 1 - 0.95^{20} \approx 0.64 \]

↑ 위양성률 α로 N개를 독립 검정하면, "적어도 하나가 우연히 유의할 확률"(집단별 오류율, FWER)이 폭증한다. 20개만 시도해도 64%다. 즉 사전 직관 없이 20개 팩터를 돌리면, 하나가 t>2를 넘는 건 거의 확실하지만 그건 대부분 우연이다.

경제적 직관은 이 "숨은 N"을 1로 줄이는 장치다. "왜 GP/A가 미래 수익성을 예측해야 하는가"를 먼저 설명할 수 있으면, 여러분은 100개가 아니라 1개를 검정한 것이다. 직관은 겉멋이 아니라 통계적 정당성의 근거다.

2.3 파이프라인을 관통하는 하나의 이야기 — Fundamental Law

디렉토리는 형식이고, 그 안을 관통하는 논리가 있어야 한다. Grinold-Kahn의 능동운용 기본법칙(Fundamental Law of Active Management)이 그 논리를 한 줄로 요약한다 — 파이프라인의 각 단계가 이 식의 어느 항을 개선하는지 알면 프로젝트가 하나의 이야기가 된다.

\[ \text{IR} \approx \text{IC} \times \sqrt{\text{Breadth}} \times \text{TC} \]

↑ 정보비율(IR) ≈ 정보계수(IC, 예측의 정확도) × √폭(Breadth, 독립 베팅 수) × 이전계수(TC, 아이디어를 실제 포지션으로 옮기는 효율). 각 단계가 이 셋 중 하나를 담당한다.

Table 2.2. 파이프라인 단계 ↔ Fundamental Law 항
단계개선하는 항어떻게
s03 팩터(R5)IC ↑더 예측력 있는 신호 정의 (GP/A의 낮은 조작성)
s06 ML(R7·R8)IC ↑여러 신호를 비선형 결합해 예측 정확도 향상
s04 유니버스(R5)Breadth ↑더 많은 독립 종목·시점에 베팅
s07 비용·구현(R11)TC ↑회전율·비용을 줄여 아이디어를 온전히 실현

이 관점이 있으면 면접에서 "당신 파이프라인의 각 단계가 무엇을 위한 것이냐"에 한 문장으로 답할 수 있다: "s03·s06는 IC, s04는 Breadth, s07은 TC를 올려 최종 IR을 극대화합니다." 흩어진 코드가 하나의 목적으로 꿰인다.

RAW = Path("data/raw"); OUT = Path("data/processed"); OUT.mkdir(parents=True, exist_ok=True)

    fs = pd.read_parquet(RAW / "raw_fs.parquet")

        monthly.sort_values("date"),
        fs.sort_values("available_from"),
        left_on="date", right_on="available_from",
        by="ticker", direction="backward",
    )
    return panel

4.2 팩터 구축 — GP/A 계산·정규화

\[ \text{GP/A}_{i,t} = \frac{\text{Revenue}_{i,t} - \text{COGS}_{i,t}}{\text{Total Assets}_{i,t}} \]

↑ 총이익(매출-매출원가)을 총자산으로 나눈 것. 분자에 순이익 대신 총이익을 쓰는 이유: 판관비·이자·세금은 회계 재량이 많이 개입되지만, 매출총이익은 상대적으로 "날것"의 수익성이라 조작이 어렵다.

# s03_factor.py — GP/A 계산 후 매월 단면 정규화
import pandas as pd, numpy as np

panel = pd.read_parquet("data/processed/panel.parquet")
panel["gpa"] = (panel["revenue"] - panel["cogs"]) / panel["total_assets"]

def winsorize(s, p=0.01):
    lo, hi = s.quantile(p), s.quantile(1-p)
    return s.clip(lo, hi)

# 핵심: groupby('date') — '그 달의 단면' 안에서만 정규화 (누수 방지)
panel["gpa_w"] = panel.groupby("date")["gpa"].transform(winsorize)
panel["z_gpa"] = panel.groupby("date")["gpa_w"].transform(
    lambda x: (x - x.mean()) / x.std()
)
panel[["date", "ticker", "z_gpa"]].to_parquet("data/processed/signals.parquet")
print(panel.groupby("date")["z_gpa"].agg(["mean", "std"]).tail(3).round(3))

4.3 포트폴리오 & FF 회귀·스패닝

매월 z_gpa 상위 십분위(롱)와 하위 십분위(숏)로 롱숏 포트폴리오를 만들고, 그 수익률을 한국판 Fama-French 5요인에 회귀한다. 절편 α가 유의하면 "FF5로 설명 안 되는 프리미엄"이 있다는 뜻이다.

\[ r^{LS}_t = \alpha + \beta_{MKT}\text{MKT}_t + \beta_{SMB}\text{SMB}_t + \beta_{HML}\text{HML}_t + \beta_{RMW}\text{RMW}_t + \beta_{CMA}\text{CMA}_t + \epsilon_t \]

↑ 롱숏 수익률을 5개 요인으로 설명하려 시도한다. 이 중 RMW(수익성 요인)가 Quality와 개념이 겹치므로 특히 주목. α가 살아남으면 GP/A는 RMW로도 스팬되지 않는 고유 정보를 가진 것이다.

# s05_tests.py — 롱숏 구성 + FF5 스패닝 (Newey-West 표준오차)
import pandas as pd, numpy as np
import statsmodels.api as sm

sig = pd.read_parquet("data/processed/signals.parquet")
ret = pd.read_parquet("data/processed/panel.parquet")[["date","ticker","fwd_ret"]]
df = sig.merge(ret, on=["date","ticker"])

def long_short(g):
    d = g["z_gpa"].quantile([0.1, 0.9])
    long_ = g.loc[g["z_gpa"] >= d[0.9], "fwd_ret"].mean()
    short = g.loc[g["z_gpa"] <= d[0.1], "fwd_ret"].mean()
    return long_ - short

ls = df.groupby("date").apply(long_short).rename("ls")
ff = pd.read_parquet("data/processed/kr_ff5.parquet")   # 한국 FF5
reg = pd.concat([ls, ff], axis=1).dropna()

X = sm.add_constant(reg[["MKT","SMB","HML","RMW","CMA"]])
# Newey-West: 자기상관·이분산에 강건한 표준오차 (R3)
m = sm.OLS(reg["ls"], X).fit(cov_type="HAC", cov_kwds={"maxlags": 6})
print(f"α(월) = {m.params['const']*100:.3f}%  t = {m.tvalues['const']:.2f}")
print(f"연율 α = {m.params['const']*12*100:.2f}%   R² = {m.rsquared:.3f}")
print(f"RMW 로딩 β = {m.params['RMW']:.2f} (t={m.tvalues['RMW']:.2f})")
Output: α(월) = 0.412% t = 2.83 연율 α = 4.94% R² = 0.318 RMW 로딩 β = 0.51 (t=4.10) → RMW와 강하게 겹치지만(β=0.51), 그래도 α의 t=2.83 로 살아남음

해석: α의 t=2.83은 단일 사전가설 검정 기준으로는 유의(t>2)하지만, Harvey et al.(2016)의 다중검정 기준 t>3.0에는 못 미친다. 정직한 리포트라면 "경계선(marginal) 유의, RMW와 상당 부분 겹침"이라고 써야 한다. 부풀려 "강력한 알파 발견!"이라 쓰면 신뢰를 잃는다.

4.4 LightGBM 결합

단일 팩터의 α가 경계선이라면, 여러 신호를 비선형으로 결합하면 나아질까? R7~R8에서 배운 LightGBM으로 z_gpa에 모멘텀·저변동성 등을 더해 랭킹을 학습한다. 단, purged CV로 누수를 막는다.

# s06_ml.py — LightGBM + purged/embargo 시계열 CV (R7·R8 핵심)
import lightgbm as lgb
import numpy as np, pandas as pd

feats = ["z_gpa", "z_mom12", "z_lowvol", "z_size"]
X, y, dates = data[feats], (data["fwd_ret"] > data.groupby("date")["fwd_ret"]
        .transform("median")).astype(int), data["date"]

def purged_splits(dates, n=5, embargo=1):
    """시간 순 분할 + 학습/검증 사이 embargo 개월 제거 (누수 차단)."""
    uniq = np.sort(dates.unique())
    folds = np.array_split(uniq, n)
    for k in range(1, n):
        tr_end = folds[k-1][-1]
        te = folds[k]
        # train은 tr_end 이전, embargo 개월 gap 후 test 시작
        tr = uniq[uniq <= tr_end][:-embargo] if embargo else uniq[uniq <= tr_end]
        yield dates.isin(tr).values, dates.isin(te).values

aucs = []
for tr, te in purged_splits(dates):
    clf = lgb.LGBMClassifier(n_estimators=300, num_leaves=15,
                             learning_rate=0.03, subsample=0.8)
    clf.fit(X[tr], y[tr])
    p = clf.predict_proba(X[te])[:, 1]
    from sklearn.metrics import roc_auc_score
    aucs.append(roc_auc_score(y[te], p))
print(f"purged CV AUC: {np.mean(aucs):.3f} ± {np.std(aucs):.3f}")
Output: purged CV AUC: 0.541 ± 0.018 → 0.5보다 유의하게 높지만 미미. 금융 데이터에선 0.54도 유의미할 수 있음 (참고: 랜덤 K-fold로 하면 0.58 나옴 — 그건 누수로 부풀려진 값!)

함정 — 0.58 vs 0.54: 같은 데이터·모델인데 랜덤 K-fold는 AUC 0.58, purged CV는 0.54가 나온다. 차이 0.04가 전부 누수다. 랜덤 분할은 "미래 달"이 학습에 섞여 들어간다. 면접에서 "왜 이 CV를 썼나?"라고 물으면 바로 이 숫자 비교를 보여줘라 — 누수를 이해하고 통제했다는 가장 확실한 증거다.

4.5 비용 후 성과 & 결론

\[ r^{net}_t = r^{gross}_t - c \cdot \text{Turnover}_t, \qquad \text{Turnover}_t = \tfrac{1}{2}\sum_i |w_{i,t} - w_{i,t^-}| \]

↑ 순수익 = 총수익 - (편도 비용률 c × 회전율). 회전율은 리밸런싱 직전 비중과 직후 비중의 절대 변화의 절반(양방향을 한 번만 세기). Quality는 재무 기반이라 신호가 천천히 변해 회전율이 낮은 편 → 비용 내성이 좋다.

4.6 강건성 점검 — 결과가 우연이 아님을 확인

단일 숫자(연 4.9%)만으로는 부족하다. 진짜 리서처는 "이 결과가 특정 선택에 의존하는가"를 스스로 흔들어본다. 하위기간, 대안 정의, 비용 수준을 바꿔가며 부호·유의성이 유지되는지 본다.

# s05_tests.py (이어서) — 강건성 그리드

    X = sm.add_constant(reg[["MKT","SMB","HML","RMW","CMA"]])

4.7 Deflated Sharpe — "몇 번 시도했나"로 샤프를 할인

비용 후 샤프 0.58이 나왔다고 끝이 아니다. 이 전략에 도달하기까지 몇 개의 변형을 시도했는가? 시도가 많았다면 그 샤프는 우연이 섞인 값이다. Deflated Sharpe Ratio(DSR)는 이 다중검정을 샤프 차원에서 보정한다.

\[ \text{DSR} = \Phi\!\left( \frac{(\widehat{SR} - SR_0)\sqrt{T-1}}{\sqrt{1 - \hat\gamma_3 \widehat{SR} + \frac{\hat\gamma_4-1}{4}\widehat{SR}^2}} \right),\qquad SR_0 = \sqrt{\text{Var}[\widehat{SR}]}\cdot\mathbb{E}[\max_n] \]

↑ DSR은 "이 샤프가 우연이 아닐 확률". 관측 샤프 \(\widehat{SR}\)를 왜도 \(\gamma_3\)·첨도 \(\gamma_4\)로 보정하고, 다중시도 시 기대되는 "최대 샤프" \(SR_0\)를 뺀 뒤 표준정규 \(\Phi\)로 확률화한다. N번 시도했다면 \(SR_0\)가 커져 문턱이 높아진다. DSR > 0.95면 신뢰할 만하다.

# DSR 근사 — 몇 번 시도했는지에 따라 문턱이 어떻게 오르나
import numpy as np
from scipy.stats import norm

def expected_max_sr(n_trials, var_sr):
    """N번 독립 시도 시 기대되는 최대 샤프 (극단치 이론 근사)."""
    e = 0.5772  # 오일러-마스케로니 상수
    z = (1-e)*norm.ppf(1-1/n_trials) + e*norm.ppf(1-1/(n_trials*np.e))
    return np.sqrt(var_sr) * z

var_sr = 1/168            # 168개월, 샤프 추정 분산 근사 ≈ 1/T
for n in [1, 10, 50, 200]:
    sr0 = expected_max_sr(max(n,2), var_sr) if n>1 else 0
    print(f"{n:3d}번 시도 → 우연 기대 최대샤프(월) SR0={sr0:.3f}  "
          f"(연 {sr0*np.sqrt(12):.2f})")
Output: 1번 시도 → 우연 기대 최대샤프(월) SR0=0.000 (연 0.00) 10번 시도 → 우연 기대 최대샤프(월) SR0=0.123 (연 0.43) 50번 시도 → 우연 기대 최대샤프(월) SR0=0.166 (연 0.57) 200번 시도 → 우연 기대 최대샤프(월) SR0=0.199 (연 0.69) → 200번 시도했다면 연샤프 0.69는 순전히 우연으로도 나온다! 우리 관측치 0.58이 이 문턱 아래면 자랑할 수 없다.

함정 — "샤프 0.58"의 진짜 의미: 위 출력을 보라. 만약 여러분이 팩터 정의·기간·분위를 200번 바꿔가며 최고를 골랐다면, 순전한 우연으로도 연샤프 0.69가 기대된다. 그러면 관측 0.58은 오히려 우연 문턱 아래다. 이래서 "시도 횟수를 정직하게 기록"해야 한다. 캡스톤에서 사전가설 1개(GP/A)만 검정했기에 0.58을 논할 수 있는 것이다 — 여기서도 사전 직관의 가치가 다시 드러난다.

워크스루 결론: GP/A는 한국 시장에서도 경계선 수준의 알파(연 4.9%, t=2.83)를 낸다. RMW와 절반쯤 겹치지만 완전히 스팬되진 않는다. 하위기간 강건성 점검 결과 전반부(t=2.71)는 강하나 후반부(t=1.88)는 약화된다. LightGBM 결합은 미미하게 개선(purged AUC 0.54). 낮은 회전율 덕에 비용 후 샤프 0.58로 생존하며, 사전가설 단일 검정이라 DSR 관점에서도 정당하다. 정직한 한 줄: "약하지만 실재하는 Quality 프리미엄, 최근 약화 조짐. 단독 알파 전략보다는 멀티팩터 조합의 한 축으로 유용." 이 정도로 겸손하고 구체적인 결론이 오히려 신뢰를 준다.

8.1 기대값 퍼즐

단골 문제: "공정한 6면체 주사위를 굴려 나온 값만큼 돈을 받는다. 단, 한 번 다시 굴릴 옵션이 있다. 최적 전략의 기대값은?"

\[ \mathbb{E}[\text{재굴림}] = \frac{1+2+3+4+5+6}{6} = 3.5 \;\Rightarrow\; \text{4,5,6은 유지, 1,2,3은 재굴림} \]

↑ 첫 굴림이 3.5(재굴림 기대값)보다 크면(즉 4·5·6) 유지, 작으면(1·2·3) 다시 굴린다. 이 임계 전략의 기대값은 아래 코드로 검증한다.

\[ \mathbb{E}[\text{최적}] = \underbrace{\tfrac{1}{2}\cdot\tfrac{4+5+6}{3}}_{\text{4,5,6 유지}} + \underbrace{\tfrac{1}{2}\cdot 3.5}_{\text{1,2,3 재굴림}} = \tfrac{1}{2}(5) + \tfrac{1}{2}(3.5) = 4.25 \]

↑ 절반의 확률로 {4,5,6}이 나와 평균 5를 확정하고, 나머지 절반은 재굴림해 3.5를 얻는다. 최적 기대값 = 4.25. 그냥 한 번 굴리는 것(3.5)보다 0.75 높다.

# 브레인티저는 손으로 풀되, 몬테카를로로 자기 답을 검증하는 습관
import numpy as np
np.random.seed(0)

def play(threshold=3.5):
    first = np.random.randint(1, 7)
    return first if first > threshold else np.random.randint(1, 7)

sims = np.array([play() for _ in range(1_000_000)])
print(f"몬테카를로 기대값: {sims.mean():.4f}  (이론값 4.25)")
Output: 몬테카를로 기대값: 4.2503 (이론값 4.25)

8.2 조건부 확률 (베이즈)

단골 문제: "어떤 병의 유병률이 1%다. 검사의 민감도·특이도가 각 99%다. 양성이 나왔을 때 실제 병에 걸렸을 확률은?"

\[ P(D|+) = \frac{P(+|D)P(D)}{P(+|D)P(D) + P(+|\neg D)P(\neg D)} = \frac{0.99 \times 0.01}{0.99 \times 0.01 + 0.01 \times 0.99} = 0.5 \]

↑ 베이즈 정리. 직관과 달리 답은 50%다 — 유병률이 낮으면(1%) 검사가 아무리 정확해도(99%) 위양성이 진양성만큼 많다. 금융에서도 같다: "희귀한 알파 신호"는 검정력이 높아도 실제로는 우연일 확률이 크다(다중검정과 같은 논리).

# 베이즈 검증 — 표로 세어보면 직관이 잡힌다 (10,000명 가정)
N = 10_000
sick = N * 0.01                 # 100명 실제 병
healthy = N - sick               # 9,900명 건강
true_pos = sick * 0.99          # 99명 (진양성)
false_pos = healthy * 0.01      # 99명 (위양성!)
print(f"양성 판정 중 실제 환자 비율 = {true_pos/(true_pos+false_pos):.1%}")
Output: 양성 판정 중 실제 환자 비율 = 50.0%

8.3 브라운 운동 기초

Definition 8.1 — 위너 과정(브라운 운동)의 성질

\[ W_0 = 0,\quad W_t - W_s \sim N(0,\, t-s),\quad \mathbb{E}[W_t] = 0,\quad \text{Var}(W_t) = t \]

↑ 브라운 운동은 (1) 0에서 시작, (2) 증분이 정규분포이고 시간 간격에 비례하는 분산, (3) 독립 증분. 표준편차가 √t로 커진다 → "가격은 시간의 제곱근으로 퍼진다". 이것이 변동성 연율화에 √12·√252가 나오는 이유.

단골 문제: "주가가 기하 브라운 운동을 따를 때, T년 후 로그수익률의 기대값과 분산은?" 답: 기대 \((\mu - \sigma^2/2)T\), 분산 \(\sigma^2 T\). σ²/2 조정항(변동성 드래그)이 핵심 함정이다.

# scripts/final_check.py — 캡스톤 자가 채점 게이트
import subprocess, json, sys
from pathlib import Path

checks = {}
# (1) 재현: make reproduce 가 성공하는가
r = subprocess.run(["make", "reproduce"], capture_output=True)
checks["reproduce"] = (r.returncode == 0)
# (2) 누수 테스트 통과
r = subprocess.run(["pytest", "tests/", "-q"], capture_output=True)
checks["no_leakage"] = (r.returncode == 0)
# (3) 핵심 그림 생성됨
checks["figure"] = Path("report/figures/cumret.png").exists()
# (4) 리포트에 '한계' 섹션 3항목 이상
rep = Path("report/report.md").read_text(encoding="utf-8")
lim = rep.split("## 6. 한계")[-1] if "한계" in rep else ""
checks["limitations"] = lim.count("\n- ") >= 3
# (5) raw 데이터·키 미커밋
tracked = subprocess.run(["git", "ls-files"], capture_output=True, text=True).stdout
checks["no_raw_committed"] = ("data/raw/" not in tracked) and ("API_KEY" not in tracked)

for k, ok in checks.items():
    print(f"[{'PASS' if ok else 'FAIL'}] {k}")
sys.exit(0 if all(checks.values()) else 1)

Quiz — R0~R11 종합

Q1. (R2) "현재 KOSPI200 구성종목 200개로 2010~2023 백테스트를 했다"의 문제는?
생존편향(survivorship bias). 지금 살아남은 종목만 보면, 과거에 편출·상폐된 부진 종목이 빠져 성과가 부풀려진다. 시점별 구성종목(누적 312개, 상폐 포함)을 써야 한다. 이것이 워크스루에서 종목 수가 200이 아니라 312였던 이유다.
Q2. (R2) 재무데이터에 DateOffset(months=4)를 더하고 merge_asof(direction="backward")로 병합하는 이유는?
룩어헤드 편향 차단. 사업보고서는 회계기간 종료 후 수개월 뒤에 공시된다. 12월 결산 재무를 1월부터 쓰면 "아직 발표 안 된 정보"를 미리 쓰는 것이다. 공시일까지 lag를 주고, as-of backward 병합으로 "그 시점에 이미 공개된 최신 재무"만 붙인다.
Q3. (R3) 월별 팩터 수익률의 t-검정에서 왜 Newey-West(HAC) 표준오차를 쓰는가?
수익률의 자기상관·이분산 때문. 일반 OLS 표준오차는 오차가 i.i.d.라고 가정하는데, 금융 수익률은 자기상관·변동성 클러스터링이 있다. 이를 무시하면 표준오차가 과소추정되어 t가 부풀려진다 → 없는 유의성을 만든다. NW는 이에 강건하다. cov_type="HAC", maxlags=6.
Q4. (R5/R6) 롱숏 포트폴리오를 FF5에 회귀했더니 α의 t=2.8, RMW 로딩 β=0.5(t=4.1)이 나왔다. 어떻게 해석하나?
팩터는 RMW(수익성)와 상당 부분 겹치지만(β=0.5), 완전히 스팬되지는 않는다(α의 t=2.8 생존). 즉 기존 요인으로 절반쯤 설명되고, 나머지는 고유 정보. 단, t=2.8은 단일가설엔 유의하나 다중검정 기준 t>3엔 미달 → "경계선"이라 정직하게 써야 한다.
Q5. (R7/R8) 같은 데이터·모델인데 랜덤 K-fold AUC 0.58, purged CV AUC 0.54가 나왔다. 무엇을 믿어야 하나?
purged CV의 0.54. 차이 0.04는 전부 누수다. 랜덤 K-fold는 시계열에서 "미래 시점"이 학습 폴드에 섞이고, 인접 시점의 자기상관으로 검증 폴드가 오염된다. purged+embargo는 학습/검증 사이에 시간 간격을 두어 이를 차단한다. 실전 성과는 항상 purged 쪽에 가깝다.
Q6. (R11) Gross 샤프 0.71인데 Net 샤프가 0.58로 떨어졌다. 이 차이를 결정하는 두 요소는?
회전율(turnover)과 거래비용률. Net = Gross − c×Turnover. Quality는 재무 기반이라 신호가 느리게 변해 회전율이 낮고(월 18%), 그래서 비용 침식이 작다(연 0.66%). 모멘텀처럼 회전율이 높은 팩터는 같은 비용률에서도 훨씬 많이 깎인다. 그래서 "비용 후 성과"를 항상 봐야 한다.
Q7. (Ch.1) 다음 중 "좋은 리서치 질문"은? (A) "AI로 주가를 맞힐 수 있나?" (B) "12-1 모멘텀 롱숏이 KOSPI200에서 2010~2023 비용 30bp 후 샤프>0.5인가?"
(B). 유니버스·기간·변수정의·비용·판정기준이 모두 명시되어 검증·재현 가능하다. (A)는 다섯 요소가 전부 비어 "예/아니오"로 판정할 수 없다. 좋은 질문 = U × [t₀,t₁] × f(·) × H₀ × τ.
Q8. (Ch.5) 리서치 리포트에서 초보가 흔히 빼먹지만, 오히려 신뢰를 만드는 섹션은?
'한계(Limitations)' 섹션. 단일시장·기간의 일반화 주의, 다중검정 미달, 비용 단순화, 대안 정의 미검증 등 자기 결과의 경계를 스스로 밝히는 것. 약점을 숨기면 오히려 초보 티가 나고, 먼저 드러내면 "자기 결과를 안다"는 신뢰를 준다.
Q9. (Ch.8) 유병률 1%, 민감도·특이도 99%인 검사에서 양성일 때 실제 환자 확률이 50%인 이유는? 이것이 퀀트 리서치와 무슨 관련인가?
유병률이 낮으면 위양성(99명)이 진양성(99명)만큼 나오기 때문(베이즈). 퀀트 대응: "희귀한 진짜 알파"를 찾을 때, 검정력이 높아도 발견된 신호가 우연(위양성)일 확률이 크다. 이것이 다중검정에서 t 기준을 올려야 하는 이유와 정확히 같은 논리다.
Q10. (Ch.6) raw 데이터를 .gitignore하고 수집 스크립트만 커밋하는 두 가지 이유는?
(1) 데이터 라이선스 — KRX·DART·유료 데이터를 repo에 재배포하면 라이선스 위반 소지. (2) 재현성 유지 — 스크립트만 있으면 남이 자기 키로 직접 받아 재현할 수 있어, 라이선스 문제 없이 make reproduce가 동작한다. 덤으로 repo가 가벼워진다.
