재무모델링을 공부할 때 가장 큰 함정은 **가짜 회사로 연습하는 것**이다. 매출이 매년 10%씩 자라는 가상의 제조업체로는 "가정을 세우는 고민"을 할 수 없다. 숫자가 틀려도 아무도 반박하지 않기 때문이다. 그래서 [Financial Modeling Guide](/financial-modeling/)를 만들면서, 마지막에는 실제 종목 하나를 골라 initiation 리포트 수준의 케이스 모델을 직접 지었다. 대상은 삼양식품(003230)이다.

## 왜 삼양식품인가

케이스 종목의 조건은 세 가지였다.

1. **사업 구조가 단순할 것** — 사업부가 10개면 첫 모델로는 과하다. 삼양식품은 라면(불닭 중심) 단일 축이라 매출 드라이버를 명확하게 쪼갤 수 있다.
2. **금융업이 아닐 것** — 은행·보험은 표준 DCF가 아니라 배당할인·초과이익 모델이 필요하다.
3. **"추정이 갈리는" 구간에 있을 것** — 2023~2025년 매출이 1.2조 → 2.35조로 뛰고 영업이익률이 12% → 22%까지 올라온 회사다. 이 성장이 이어질지, 정상화될지에 따라 밸류에이션이 크게 갈린다. 가정 하나하나가 실제 논쟁거리가 되는 종목이라 연습 재료로 이상적이었다.

## 모델 구조

워크북은 8개 시트가 한 방향으로 흐르도록 설계했다. 셀 컨벤션은 실무 표준을 그대로 따랐다: **파랑 = 직접 입력, 검정 = 수식, 초록 = 타 시트 링크**.

| 시트 | 역할 |
|------|------|
| 케이스노트 | 투자포인트 2~3개, 리스크와 반박, 데이터 출처, 모델의 한계 명시 |
| 가정 | 매출 드라이버·마진·시나리오 입력이 모이는 유일한 입력 허브 |
| IS | 손익계산서 — 실제 공시 실적 + 추정연도 |
| BS / CF | 재무상태표·현금흐름표 — 간이 스케줄 (아래 '한계' 참고) |
| Ratios | 수익성·성장성·레버리지 비율 대시보드 |
| DCF | FCFF 할인 — WACC·영구성장률 민감도 표 포함 |
| Output | 목표주가 레인지와 투자의견 자동 산출 |

핵심 설계 결정 몇 가지:

- **시나리오 토글 (Base / Bull / Bear)** — 셀 하나(`SCN`)를 바꾸면 매출 성장률·마진 가정이 통째로 전환되고, DCF와 투자의견까지 한 번에 다시 계산된다. 가정 시트 밖에서는 아무것도 손대지 않아도 된다.
- **성장 둔화를 기본 시나리오로** — 최근 2년의 폭발적 성장을 그대로 연장하는 대신, 고성장 후 정상화 경로를 Base로 놓았다. 낙관은 Bull 시나리오의 몫이다.
- **자동 검증** — 대차일치(Balance check)가 시트에 상시 표시된다. 모델이 커질수록 "어디서 안 맞는지"를 찾는 비용이 커지므로, 검증은 나중에 붙이는 게 아니라 처음부터 골격에 넣었다.
- **투자의견 자동 매핑** — DCF 목표주가와 현재가 괴리율이 Output 시트에서 매수/중립/매도 의견으로 자동 매핑된다. 판단을 수식으로 강제하면 "숫자 따로, 결론 따로"가 불가능해진다.

## 밸류에이션에서 배운 것

DCF는 **하나의 점**(내재가치)을 주고, 상대가치는 **하나의 밴드**(시장이 매기는 배수)를 준다. 둘은 거의 항상 다르다. 이 모델을 지으면서 얻은 가장 큰 교훈은, 그 차이를 없애려고 가정을 역산하는 게 아니라 **차이가 왜 나는지 설명할 수 있어야 모델이 완성된다**는 것이다. DCF 민감도 레인지와 피어 밴드를 같은 축에 올려놓고 겹치는 구간을 보면, 내 가정이 시장 컨센서스 대비 어디서 공격적인지가 그대로 드러난다.

## 이 모델의 한계 (명시)

- 손익계산서는 실제 공시 실적 기반이지만, **BS/CF는 간이 스케줄**이다. 운전자본·CAPEX를 매출 연동 비율로 단순화했고, 파일 첫 시트(케이스노트)에 이 한계를 그대로 적어 두었다.
- 개인 학습·포트폴리오 목적의 케이스 스터디이며, 투자 추천이 아니다.
